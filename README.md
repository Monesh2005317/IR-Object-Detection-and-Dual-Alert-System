#  Transistor-MOSFET Based IR Object Detection and Dual Alert System

A hardware-based IR object detection and alert system developed using discrete electronic components without using any microcontroller.

---

# 📌 Project Overview

This project detects nearby objects using an IR sensor and activates:
-  LED indication
-  Buzzer alert

The system demonstrates:
- IR sensing
- Transistor-based signal inversion
- MOSFET switching
- Hardware automation system design

---

# ⚙️ Working Principle

The IR sensor continuously emits infrared rays and detects reflected IR signals from nearby objects.

## When no object is present:
- IR sensor output remains HIGH
- BC547 transistor turns ON
- MOSFET remains OFF
- LED and buzzer remain OFF

## When object is detected:
- IR sensor output goes LOW
- BC547 transistor turns OFF
- MOSFET turns ON
- LED and buzzer activate instantly

The BC547 transistor is used for signal inversion while the IRFZ44N MOSFET acts as a low-side electronic switch.
